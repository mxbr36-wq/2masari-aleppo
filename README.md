# مساري

منصة اختبار توجيه جامعي لطلاب الثانوية في سوريا، يقدّمها اتحاد طلبة سورية (فرع حلب).

للتفاصيل الكاملة (كيف يعمل المشروع، ومهام شائعة، وقرارات سابقة، وما بقي) اقرأ [`HANDOVER.md`](HANDOVER.md).

## المميزات

- اختبار تفاعلي من 18 سؤالاً، تُسحب من بنك يضم 98 موقفاً
- 7 أبعاد، 31 تخصصاً جامعياً، 5 اتجاهات دراسية
- النتيجة: اتجاهان × تخصصان، مع مستوى ثقة
- حفظ التقدم تلقائياً (الأسئلة والإجابات والفرع فقط؛ الاسم والهاتف لا يُحفظان في المتصفح)
- مشاركة النتيجة كصورة مع رمز QR
- وضع داكن، وتتبدّل الشعارات بين الوضعين
- مساعد ذكي (مساري AI) يجيب عن أسئلة الدراسة الجامعية

## التقنيات

JavaScript (وحدات ES) بلا مكتبات خارجية، HTML وCSS، `localStorage`، Canvas. المساعد الذكي يعمل عبر Cloudflare Worker.

## هيكل المشروع

| الملف | الدور |
|---|---|
| `index.html` | هيكل الصفحة وشاشاتها (ترحيب، تسجيل، أسئلة، نتيجة) والنوافذ |
| `theme-init.js` | يطبّق الوضع الداكن قبل أول رسم كي لا تومض الصفحة |
| `app.js` | نقطة الدخول: التخزين، محرك الاختبار، الواجهة، تصدير النتيجة، الملاحظات |
| `questions.js` | بنك الأسئلة (كل خيار تحت اسم البُعد الذي يشير إليه) |
| `dimensions.js` / `directions.js` / `specializations.js` | الأبعاد والاتجاهات والتخصصات وبصماتها |
| `scoring.js` | خوارزمية الحساب والثقة |
| `chatbot.js` / `chatbot.css` | واجهة المساعد الذكي وتنسيقها |
| `icons.js` / `glow.js` | سجل الأيقونات، والتدرجات والمخطط الخطي |
| `qr.js` | مولّد QR بلا مكتبات |
| `style.css` / `glow.css` | التنسيق الأساسي وطبقة التحسينات (تُحمَّل بعده) |
| `assets/` | الشعارات والصور (انظر أدناه) |
| `worker/` | كود Cloudflare Worker الخاص بالمساعد |
| `tools/simulate.mjs` | فحص معايرة النتائج |
| `fingerprint-changes.md` | آخر تعديلات على بصمات التخصصات |
| `HANDOVER.md` | دليل المشروع للمطوّر القادم |

## كيف تُحسب النتيجة

1. درجة كل بُعد = نسبة المرات التي اختاره الطالب حين عُرض عليه، مع قيمة أولية للتنعيم.
2. تُحوَّل الدرجات إلى متجه بترتيب `DIMENSION_KEYS`.
3. يُحسب معامل ارتباط بيرسون بين المتجه وبصمة كل تخصص، ثم يُحوَّل إلى نسبة مع معايرة صغيرة لكل اتجاه (`DIRECTION_CALIBRATION` في `scoring.js`).
4. تُجمَّع التخصصات حسب الاتجاه، ويُختار أعلى اتجاهين وأفضل تخصصين في كل منهما. طالب الفرع الأدبي لا يرى إلا التخصصات الأدبية والمشتركة.
5. تُحسب الثقة من الفجوة بين الاتجاهين، وتُخفَّض إذا كانت جودة الإجابات ضعيفة (نمط ثابت، اختيارات متقاربة، أسئلة قليلة).

بعد تعديل الأسئلة أو التخصصات أو بصماتها شغّل:

```bash
node tools/simulate.mjs
```

يطبع توزيع الاتجاه الأول للإجابات العشوائية (الهدف نحو 20% لكل اتجاه في العلمي)، ومدى عدالة ظهور التخصصات، والملفات النموذجية التي لا تحصل على التخصص المتوقع لها. وعدّل `DIRECTION_CALIBRATION` إن ابتعدت النسب.

## التشغيل محلياً

الملفات وحدات ES، فلا تعمل من `file://`. شغّلها عبر خادم ثابت:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الإعداد

- **المساعد الذكي:** المتصفح يرسل إلى `WORKER_URL` (في `chatbot.js`) المحادثة وملخص النتيجة فقط: `{ messages, context }`. تعليمات النموذج والموديل والحدود كلها داخل `worker/worker.js`، فلا يستطيع أحد تغييرها من المتصفح. أنشر الـ Worker قبل نشر الواجهة الجديدة، وإلا يعمل المساعد من بيانات التخصصات المحلية فقط:
  1. عدّل `worker/wrangler.toml` (`ALLOWED_ORIGINS` و`LLM_API_URL` و`LLM_MODEL`).
  2. `npx wrangler secret put LLM_API_KEY`
  3. `npx wrangler deploy` ثم ضع عنوانه في `WORKER_URL`.

  فحص `Origin` يوقف الاستخدام العشوائي من المتصفحات فقط، والحماية الفعلية هي حدّ المعدل (`RATE_LIMITER` في `wrangler.toml`).
- **جمع البيانات:** تُرسل بيانات التسجيل والملاحظات إلى Google Forms، وأرقام الحقول في `app.js`. الحماية من التكرار في المتصفح تمنع الضغط المتكرر العادي فقط، وأي حماية فعلية من الإرسال المباشر تكون عند النموذج نفسه.
- **سياسة الأمان (CSP):** معرّفة في `index.html` وتمنع السكربتات والأنماط المضمّنة (لا تضف `<script>` أو `style=` داخل الصفحة). النطاقات المسموحة: الخطوط من Google، وGoogle Forms، وعدّاد الزيارات، والـ Worker. الحماية من تضمين الصفحة داخل إطار (`frame-ancestors`) لا تعمل من وسم `<meta>`، وتحتاج ترويسة من الاستضافة.
- **الإصدار:** رقم `?v=` (الآن `2.1`) في روابط `index.html` واستيرادات الوحدات و`tools/simulate.mjs` يجب أن يكون واحداً في كل الملفات، ويُرفع عند كل نشر لإبطال كاش المتصفح.
- **ترتيب ملفات CSS:** `glow.css` يجب أن يُحمَّل بعد `style.css`، وقواعده تعتمد على الترتيب فلا تدمج ولا تُرتّب محدّداته.
